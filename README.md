# Senko Assistant — установщик, автосохранение, обновления

## 1. Один раз: создать репозиторий на GitHub
1. github.com → **New repository** → имя, например `senko-assistant` → **Public** (нужен, чтобы приложение читало обновления без токена) → Create.
2. В `main.js` адрес репозитория уже прописан (Kofemanchik/Senko-Assistant).
3. Загрузите в репозиторий всё содержимое этой папки (кроме `node_modules`): `git init`, `git add -A`, `git commit -m init`, `git remote add origin ...`, `git push -u origin main`.

## 2. Получить установщик `Senko Assistant Setup.exe`
**Вариант А — GitHub сам соберёт (ничего ставить не нужно):**
`git tag v1.0.0 && git push --tags` → вкладка **Actions** → через пару минут `.exe` появится в **Releases**.
**Вариант Б — на своём ПК (Node.js 20+):** `npm install`, затем `npm run dist`. Файл будет в `dist/`.

Установщик в один клик: ставит приложение, создаёт ярлык **Senko Assistant** с вашей иконкой на рабочем столе и в «Пуск», запускает программу. Админ-права не нужны. Удаление — через «Приложения и возможности».

## 3. Как обновлять законы без новой сборки
1. Правите `app/index.html`.
2. `npm run publish-update -- 1.0.1 "Что изменилось"`
3. `git add -A && git commit -m "v1.0.1" && git push`

У всех пользователей при запуске (и раз в 3 часа) приложение скачивает новый `index.html`, проверяет хэш и предлагает перезагрузить. Если интернета нет — работает с тем, что уже есть.

## 4. Автосохранение
Все данные памятки (`bos-*`: избранное, заметки, журнал, профиль, настройки, фото) каждые 3 секунды зеркалятся в файл
`Документы\Senko Assistant\Автосохранение\senko-data.json`
плюс по одной копии в день (последние 14) в подпапке «Резервные копии».
Если данные в приложении пропали (переустановка, очистка), при запуске они автоматически восстанавливаются из файла. Перенос на другой ПК: скопируйте папку `Автосохранение` на новый компьютер.
