# Как добавить сервер Majestic RP

У каждого сервера свои игроки, законы и настройки. Сервер определяется номером из игры (Boston — 12, Los Angeles — 7, Denver — 16).

1. **Список серверов** — впишите `id`, название и номер раздела «Законодательная база» на форуме (число в адресе `.../zakonodatel-naya-baza.<номер>/`) во все места:
   - `scripts/servers.js` (сбор законов в GitHub Actions);
   - `supabase/functions/senko/index.ts` — `SERVERS`;
   - `accounts.js`, `site/app/web-auth.js`, `site/panel/panel.js`, `app/auth.html` — списки для выбора сервера.
2. **Законы** — запустите Actions → Sync laws. Появятся `update/laws-<id>.enc` и `update/laws-status-<id>.json` (у Boston файлы называются без номера, чтобы старые версии программы продолжали работать). В сводке запуска будет отчёт `check-laws`: число статей, звёзд и штрафов по каждому кодексу. Если цифры странные, проверьте раздел вручную.
3. **Пилот** — пока флаг `srv29` в панели владельца («Функции») стоит в режиме «Бета», новые серверы видят только бета-тестеры. Включите «Всем», когда проверите законы.
4. **Таблицы в программе** — для любого сервера кроме Boston таблицы УК/АК/ДК/ПК пересобираются из его законов при старте. Пока законов сервера нет, показываются таблицы Boston с предупреждением.
5. Задеплойте функцию (Actions → Deploy function), затем выпустите новую версию программы.
